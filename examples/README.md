# Examples

This directory mirrors the curated list at [docs/examples.md](../docs/examples.md). The canonical entry list lives there; this file is a short pointer plus the submission instructions.

## Submit an example

If you've built a rootless app and want it listed:

1. Open [docs/examples.md](../docs/examples.md).
2. Add an entry using the submission template at the bottom of that file.
3. Open a PR.

Alternatively, file an issue with the [submit-example](https://github.com/baditaflorin/rootless-computing/issues/new?template=submit-example.md) template and a maintainer will add it.

## What counts as a rootless app?

The shortest test: **fork the repo, enable Pages on the fork, open the URL — does it work?** If yes, it's almost certainly rootless. If the fork is non-functional without further setup, it isn't.

For the longer definition, see the [manifesto](../MANIFESTO.md) and the [vocabulary](../docs/vocabulary.md).
