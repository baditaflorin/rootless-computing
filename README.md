# Rootless Computing

A category of software with no origin server. The repository is the distribution; the browser is the runtime; the user's machine is the database. Peers coordinate directly. Trust, when needed, is proved cryptographically rather than asserted by a host.

> **[Read the Manifesto →](MANIFESTO.md)**
> *Version 0.1 — 2026-05-12*

This repository is the canonical home for the term: the manifesto, the vocabulary, the principles, the examples, and the path for others to contribute. It is itself a rootless app — there is no server behind this page, and any fork is an equally legitimate copy.

## The four-layer vocabulary

| Layer | What it is |
|-------|------------|
| **Rootless-First** | The design stance. Assume no server; allow one only as enhancement. |
| **Rootless Apps** | The category. Apps with no origin, no privileged runtime coordinator. |
| **Rootless Runtime** | The architecture. Baked artifacts + browser compute + peer coordination. |
| **The Manifesto** | The document. Codifies the principles. Dated. Citable. Forkable. |
