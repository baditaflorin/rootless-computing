Interactive Demos

There is a fleet of 134 live P2P demos built using the rootless computing paradigm and the shared mesh-common framework. Each application has no origin server, runs entirely in the browser, stores data locally on your machine, and coordinates directly with peers using WebRTC/Yjs.

💡 You can also browse the live interactive running dashboard to see side-by-side recordings and status information for every demo.
