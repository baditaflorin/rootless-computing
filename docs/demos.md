# Mesh demos

The published [live demo directory](https://baditaflorin.github.io/rootless-computing/demos.html)
is deliberately not maintained as a hand-written application list. It renders
the current recorded Mesh fleet from the shared public catalog:

`https://baditaflorin.github.io/mesh-common/demos/catalog.json`

That feed is generated from each recorded demo, the service registry, and the
central taxonomy. It exposes the app ID, name, description, live and source
URLs, recording URLs, status, TRL, category, subcategory, and use cases, so
other static sites and tools can consume exactly the same up-to-date directory.

For side-by-side recordings and fleet status, use the
[Mesh dashboard](https://baditaflorin.github.io/mesh-common/demos/).
