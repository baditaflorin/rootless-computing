# Interactive Mesh Demos (134 Apps)

This page lists the **134 peer-to-peer browser applications** built using the [Rootless Computing](https://baditaflorin.github.io/rootless-computing/) paradigm and the [mesh-common](https://baditaflorin.github.io/mesh-common/) framework. 

Each app has no origin server, runs entirely client-side, stores data locally in your browser, and coordinates directly with other peers in the room using WebRTC and Yjs.
