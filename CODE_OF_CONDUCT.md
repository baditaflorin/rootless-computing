# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Short version

- Engage with ideas, not people.
- Disagree freely; argue the substance.
- Assume the other person is making a good-faith point until shown otherwise.
- Project maintainers may remove contributions or block accounts that consistently make participation unproductive.

## Reporting

If you need to flag a concern about behavior in this project, open a private email thread with the maintainer at the address listed on https://badita.org. Reports are read by Florin only.

## Scope

This applies to all project spaces — issues, pull requests, discussions, and any external channels where someone is acting as a representative of the project.
